# 英文文献的中文译文与解读：体例和核对流程

适用：导师布置的英文文献，需要交“正文中文译文 + 详细解读”；或对已有的中文译稿做质检和修订。
改编自用户电脑上 `zh-research-text-norms` 技能的同名文件（2026-11），核对步骤按本机工具调整。
标点、数字、单位、术语等写法按 `../../research-paper-writing/references/text-conventions.md`。

## 一、体例约定（写译稿和改译稿都按这一节）

1. **译文忠实。** 不弱化，也不加强原文的断言。原文写 strongly predicted，译“有力地预测”；原文写 is associated with，
   译“与……有关”，不写成“参与”“导致”。原文的限定词（only、may、in both cases、healthy）不能丢。
2. **审校意见与译文分开。** 译者或审校者的判断一律写成“（译注：……）”，紧跟在所评议的句子之后，不能不加标注混进译文。
   较长的评议放到“解读”部分，译注里写“见解读部分评议”。
3. **原文自身有矛盾时**，照录原文，加译注指出矛盾和出处，例如“正文写 RNDR，图5D 与图注写 RNMR”。不替作者改正。
4. **原文越界时**（如综述把相关写成机制，或引用的文献与论断不符），先忠实译出，再用译注说明证据边界，
   例如“r=0.265，相关程度中等偏弱”。
5. **称呼统一。** 多篇文献时全稿用“文献一/二/三”指代；同一脑区、同一概念只用一个中文译名，首次出现附英文全称和缩写，
   例如“前扣带皮层（anterior cingulate cortex，ACC）”。
6. **图注要完整。** 图注中带结论的句子（标题、“校正后仍如此”“贡献最大的边是……”）必须译出，不能只剩分图目录。
7. **数字照原文。** p 值、r 值、CI、样本量和坐标的正负号照抄原文；原文前后不一致的数字照录并加译注。
8. **解读不冒充原文。** 解读与译文分开呈现，解读里的观点写明是解读者的判断。

## 二、核对流程

1. **备份。** 动手前把原译稿复制到同目录的 `_qa/backup/`，文件名注明“××前备份”；已有同名备份时不覆盖。
2. **抽取**（工具见 `research-toolkit` 技能）：
   - 英文 PDF：`pdf_tools text 原文.pdf --outdir 工作目录`，按页抽出文字，每页有“===== 第 N 页 =====”标记。
   - Word 译稿：`docx_tools extract 译稿.docx --format md` 转成 Markdown；译稿本来就有 Markdown 源稿时直接读源稿。
   - 按文献切块，每块包含该篇的译文、图注、表格和对应的解读。
3. **分篇核对**（可以并行交给多个子代理，每个子代理一篇）：
   - 逐段对照原文检查：数字与统计量；方向（正负、增强或减弱、哪组对哪组）；限定条件；相关与因果；
     承载信息的句子有没有漏译；术语前后是否一致；上一轮的改动有没有带来新错。
   - 每条问题写明：位置、现文（逐字摘录，在全文中唯一）、建议改为、类型、严重度、原文依据（页码 + 英文原句）、说明。
   - 严重度分三档：高＝数字、方向或结论错误；中＝语义偏差、边界丢失、评议混入译文；低＝术语不统一、小的漏译。
   - 不凑数：没有问题就写没有。忠实的压缩和改写不算问题。
4. **主核验**（负责人亲自做，不能只信子代理）：
   - 用 `pdf_tools search 原文.pdf --pattern "片段"` 确认子代理引用的英文原句确实在 PDF 里。`--pattern` 是正则表达式：
     取 5～8 个有区分度的连续单词，括号、句点等特殊字符前加反斜杠，单词之间写 `\s+`，以容忍抽取文字中的换行。
     找不到时换更短的片段再查；跨行断词或双栏排版会把句子拆开，不能因为查不到就判定引文有误。
   - 涉及图中数值、表格列位、正负号的条目，必须看原页面核对：用本技能的页面渲染方式（见 `../SKILL.md` 的 DSHM 说明）；
     本机渲染不了时，请用户截图或在电脑上核对，不凭抽取出的文字判断。
   - 逐条决定采纳、修改或驳回，形成修改清单：编号、位置、程度、原来的写法、改为、原文依据（中文）、说明。
5. **应用修改**：
   - 有译稿的 Markdown 源稿时：改源稿，用 `md2docx` 生成新文件，不覆盖原文件；核对无误后再替换。
   - 只有用户给的 Word 文件时：本机没有能保留原格式、原地修改 docx 的工具。交付修改清单，由用户或电脑上的工具修改；
     经用户同意后，才改为从 Markdown 重新生成，并先说明原有格式会丢失。
6. **核验修改。** 用 `docx_tools extract` 重新抽取新文件：清单里的新文都在，旧文都已消失，清单以外的段落没有变化。
   字体按 `research-toolkit` 的默认字体规范核对。
7. **修订记录。** 另出一份中文修订记录（Markdown，需要时用 `md2docx` 转 Word），逐条列出编号、位置、程度、原来的写法、
   改成、原文依据、说明。原文依据用中文转述，必要时括注个别英文术语。汇报一律用中文。

## 三、上一轮常见错误（下次优先查）

- 作者的断言被悄悄弱化：“抑制性影响”译成“减少干扰”，“过度使用”译成“长期使用”，“机制性见解”译成“帮助理解”。
- 审校意见没加标注就写进译文，有时还与作者原意相反。
- 上一轮改写引入指代歧义：如“后一断言”按就近原则会指向另一句。
- 图注只剩分图目录，结论句全部漏掉。
- 同一结构出现两个译名：额眶皮层/眶额皮层、缝核/中缝核、前扣带回/前扣带皮层。
- 解读里的样本拆分说法与表格矛盾，例如 7T“不参与测试”与表中“97 名 7T 测试”冲突。
- 摘要里加了原文没有的限定词（“相对压力特异性”）。
